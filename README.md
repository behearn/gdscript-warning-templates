# GDScript Warning Tooltips

Godot 4.7 editor plugin. GDScript warnings show as an icon in the script editor info gutter, between breakpoints and line numbers. Hover the icon for the warning text. Click it to show that text immediately.

## Install

Copy `addons/gdscript_warning_tooltips` into your project's `addons` folder. Enable **GDScript Warning Tooltips** under Project > Project Settings > Plugins.
